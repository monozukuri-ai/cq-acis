# トレラント境界と有限 UV トリム

[English](tolerant-trims.md) | 日本語

0.3.3 で有限 UV と基本的なトレラント境界、0.3.4 で保存された次数 1/3 の
UV スプラインと局所 TEDGE 許容値に対応しました。0.3.5 のソースには inline
coedge と支持面付き交線が含まれます。以下の再パラメータ化と頂点対応は未公開です。
共有モデル API 2 と既存の raw エンティティは変更していません。

## 境界と支持面

保存された方向、端点パラメータ、ループの相互参照を検査します。有限 UV は
クランプされた支持面のノット領域の部分集合でなければなりません。トリム全体が
領域内にあることを検査し、領域外への投影やクリップでは救済しません。
UV の丸め許容値は `1e-10` または大きな座標の 64 ULP です。

`linear_surface_pcurve()` と `spline_surface_pcurve()` は保存 UV、区間、次数、
ノット・極、向き、fit 許容値、支持面の定義元を保持します。曲線の `C(-t)` と
支持面の法線反転は独立です。未知の周期性、有理 UV、チャート変換、未消費の
フィールドは、この保存 pcurve プロファイルでは受け付けません。

TEDGE の許容値は、同じ支持面の保存 UV を検査できる場合に限り、
`saved_scalar * placement_scale_to_mm + original_model_resolution_mm` とします。
これは ASM 22700 / embedded 22601 の観測済みプロファイルであり、ベンダー仕様の
一般的な解釈ではありません。相似変換のみを対象とし、元の 3D 曲線、支持面、
有限 UV とモデル全体の `resabs` を維持します。`source_edge_tolerances` に
保存値と実測値を記録します。他の fit や頂点許容値で TEDGE の上限を増やしません。

## Inline coedge と支持面付き交線

`TolerantCoedge.inline_curve` は、観測済みの完全な `par_int_cur` から、3D fit、
平面・球・トーラスの支持面、保存 UV、次数・重み・ノット、元の値範囲を返します。
平面 UV のスケールと球・トーラスの角度順序を反映します。inline fit と自身の
支持面の整合性、共有 3D 辺と UV の整合性を別々の許容値で検査します。
平面上の単一有理二次短円弧では、Bernstein 係数、角度の単調性、半平面、端点の
検査で同じ円錐曲線と確認できた場合に解析的なパラメータを使用します。
`inline_reparameterizations` に検証結果を残します。

検査済み inline 使用またはその相互参照先で局所端点許容値を確認できます。
OCCT 頂点は保存座標に置き、UV 接続には同一の元 TVERTEX ID と支持面上の距離を
要求します。通常の直線辺は、保存点が元の直線上かつ保存区間内にある場合だけ
区間を狭められます。平面穴の向き補正は `FixOrientation` のみで、全辺の同一性を
確認します。

`NativeModel.supported_curve()` は完全な `int_int_cur` の 3D fit、ファイル内の
スプライン定義、第二支持面の平面、UV と元データを返します。保存 3D fit の
第一支持面への投影を全区間で検査し、第二支持面には正の重みによる凸包上限を
用います。両方とも元の fit 許容値を維持します。保存 UV の元のパラメータ不一致も
診断に残します。これは支持面ごとの距離検査で、厳密な交線の証明ではありません。

## 未公開のトリム再パラメータ化と頂点対応

保存 UV を厳密なノット挿入で Bezier 区間に分割し、区分的な単調アフィン写像で
共有辺のパラメータに対応付けます。最近点は対応ノットの選択に使い、採用可否は
各区間と曲線全体の 3D 誤差で判断します。元の軌跡、順序、端点、有限 UV 領域を
維持し、再近似・クリップはしません。逆行や許容値超過は拒否します。
`saved_pcurve_reparameterizations` に新旧ノットと誤差を記録します。

検査済み `int_int_cur` と同じ支持面を参照する保存 UV fit は、自身の保存 fit
許容値と元の `resabs` で UV/3D 誤差を検査します。3D fit の両支持面への誤差は、
引き続き 3D fit 自身の上限で独立に検査します。`associated_pcurves` に双方の
保存値を記録し、頂点の許容値を曲線や UV の上限へ流用しません。

頂点の限定プロファイルは、flag 1、旧 scalar -1、検査済み完全 `int_int_cur` を
持つ通常の owner 辺を要求します。残り2つの保存値が、全接続辺の元の 3D 端点と
保存頂点との最大距離を厳密に囲み、その差が元の `resabs` 以内であることを検査します。
頂点の許容球が接続辺や反対側の頂点を取り込む場合は拒否します。外側の保存値は
OCCT 頂点のみに適用し、保存座標、3D 極、辺・UV の許容値は変更しません。
過小・過大な保存値、未知の接続曲線、異なる ID の接続は拒否します。
`tolerant_vertex_envelopes` に全接続辺、距離、元の座標・値・owner を記録します。
この観測済みプロファイルは TVERTEX 全般のベンダー仕様を保証するものではありません。

FTC07 2021 のローカル回帰では、残っていた面 332、1164、2336、4351 を含む
258/258 面、有限 UV の 8/8 面、206/206 トレラント coedge 境界が妥当です。
全体も 258 面を保持する閉じた有効な1ソリッドに変換できます。
Inventor の現行 Model State やベンダーとの一致は未検証です。

詳細な API と制約は [モデル API](model-api.ja.md)、各検査の診断名と根拠は
[英語版](tolerant-trims.md) を参照してください。
